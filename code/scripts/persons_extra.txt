# 补充名录：弟子、君主、寓言人物
#
# `characters.ts` 与 `lineage.ts` GHOSTS 收的是诸子本人（106 名）。但原文里出现
# 最密的人名往往不是诸子，而是他们的弟子、所对的君主、与寓言里的角色——
# 《论语》满篇子路颜渊，《列子》满篇黑卵飞卫，《公孙龙子》通篇对孔穿平原君说话。
#
# 统计量分不出这些与真概念之别：「颜渊」内聚满分、边界自由、df 低故 idf 高——
# 好词的三项特征它全有。只能靠名录。
#
# 这份名录与 `sikuLineage.ts` 那张手写的 传/承/采/驳 边表性质不同，不可相提：
# 说「颜渊是个人」不主张任何学术判断，说「《孟子》驳杨墨」才是主张。前者是参
# 考数据，后者是论断——图谱要替掉的是后者。故此表手写无妨，且应手写：可审、
# 可改、可增。一行一名，`#` 起首为注。单字不收（扫起来满篇皆是）。
