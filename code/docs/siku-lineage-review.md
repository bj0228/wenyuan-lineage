# 中国典籍关系边统一复审报告

复审对象为 `SIKU_EDGES` 中现存的 437 条中国典籍关系边，其中包含早期人工边、题名结构边和《四库全书总目提要》证据边。复审采用同一套七类定义，不以“同作者、同体裁、时代相近”单独作为正式关系依据。

## 审定口径

- **通过（accepted）**：说明能够指向具体文本、注译、选编、续作、明确批评对象或稳定的接受史并称。
- **改正（corrected）**：关系本身成立，但原关系类型或箭头方向不准确。
- **待补证（pending）**：关系具有合理性，但当前说明只有思想相近、体裁沿袭或时代衔接，尚缺具体篇章、引文或可靠书目来源。
- **剔除（rejected）**：同书异名、书与篇的包含关系、仅同作者或同体裁等，不属于既定七类关系。

证据分级为：A-source（已有来源、原文或明确题名结构）、B-curated（经策展复审判定成立，尚未附逐字来源）、B-structural（可由目录收录、注译、选编等结构直接核验）、C-claim（待补学术来源）、X-invalid（不符合关系定义）。

## 第二轮补证结果

原有 68 条待补证边经过第二轮全文与学术来源检索后全部收口。其中 5 条获得硬证据并进入正式图谱：《朱子语类》→《传习录》、《春秋繁露》→《论衡》、《世说新语》→《聊斋志异》、《世说新语》→《儒林外史》、《东京梦华录》→《都城纪胜》。其余边先按严格来源标准退出正式图谱，不再无限期挂为“待补证”。

第三轮进一步区分“来源证据”和“策展判断”：经人工按七类定义逐条裁定，39 条文学、思想与史学谱系边以 B-curated 级别恢复，其中 7 条同时改类；《三国志》→《后汉书》和《管子》→《商君书》仍删除。另有仅凭朝代相接建立的 11 条正史“相续”边，以及仅凭同属诗话体裁建立的 11 条《六一诗话》“承学”边，继续剔除。因此，原 68 条最终为 44 条进入正式图谱（5 条 A-source、39 条 B-curated），24 条剔除，0 条待定。

## 剔除的主要问题

15 条剔除边包括：《昭明文选》与《文选》这种同书异名；《四书章句集注》与组成篇目的包含关系；仅凭同作者连接《读通鉴论》与《姜斋诗话》；仅凭同为选本连接《千家诗》与《宋诗一百首》等。这些关系会制造可视化连线，却不能说明七类关系中究竟“传过去了什么”。

## 可复现性

完整的逐边状态、理由和原关系保存在 `app/world/sikuLineageReview.ts`。执行 `npm run audit:siku-lineage` 可复核覆盖率、审定规则匹配、端点、重复边、自环和正式图谱数量。
