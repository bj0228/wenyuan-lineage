# 成书之年

朝代长卷与书卡上那一行年份，出自 `scripts/siku-year.mjs` 手定的一张表。全目著录一千零一十九部，**系年二百八十五部**，余七百三十四部不印年——那一处留白，不印问号，也不印「年未详」。

## 一、为何不是人人有年

断代（`scripts/siku-era.mjs`）必须人人有：长卷的横轴是代，无代便无处可落，故判据不全者另立「代未详」一段收着。年不同。年是**旁注**，不是坐标；考得出才写。

给考不出的书编一个年，就是编造。此例与关系表的「判据不全则不入表」、断代表的「判据不全则不入代」同出一意：**图上宁留一处空白，不添一条伪据。**

最大的一类不收，是先秦诸子。《论语》《老子》《庄子》《山海经》非一时一手所成，载籍无年，后人所推各不相同——不收不是疏漏，是判据不足。故一千余部里「先秦」一段五十二部，而系年者只二部（《逸周书》《李斯谏逐客书》，前者系一段，后者有本传可系）。

## 二、年之两式

```js
"前赤壁赋": 1082          // 定得到一年：壬戌之秋七月既望，赋中自记
"史記": [-104, -91]       // 只定得到一段：太初改历始撰，征和二年报任安书时已就
```

**一个数是一年，两个数是一段（含两端）。** 公元前作负数（前 91 年 = `-91`；无公元零年，故 `-1` 之后即 `1`，脚本自校会挡下 `0`）。

二百八十五部中，定到一年者一百六十七部，只定到一段者一百一十八部。定不到一年的写一段，**不取中数充作一年**——中数是一个从未有人说过的年份，比一段更像编的。

## 三、取年之例

**一、与断代同一口径。** 取成书（撰成、奏进、刊行）之年，不取所记之时、所托之名。凡断代表把某书断在本体一边者，年亦取本体，两表相随：《三家注史记》断汉不断三家注之唐，年便取司马迁的 `[-104, -91]`；《金匮要略》断汉，年便取张仲景的 `[200, 210]`，不取林亿治平三年校刊之年。

**二、单篇取撰作之年。** 别集一类有百余部本是单篇，篇自有其年，且往往比书更确——《兰亭集序》永和九年（353）、《前赤壁赋》元丰五年（1082）、《李斯谏逐客书》秦王政十年（前 237）。文中无年、本传亦不系者（《爱莲说》《童心说》《高洁说》之属）不收。

**三、只知其段者写段。** 始撰与成书相去甚远者（《资治通鉴》治平三年置局、元丰七年奏上，作 `[1066, 1084]`），或载籍只说「某某年间」者（《幕学举要》乾隆间刊，作 `[1736, 1795]`），一概写两个数。

**四、不可考者不收。** 见第一节。

**五、年须落在代内。** 所系之年若不在断代表所断那一代的年限之内，即是两表有一处错，脚本报出不写。

## 四、第五例照出来的东西

自校不是摆设。头两批编完，它照出十三处，其中三类值得记下：

**一类是我认错了书。** 目录「经学其他」有一部《毛詩》断汉，我按《毛诗正义》系了唐贞观之年——其实那是毛亨的传，不是孔颖达的疏。《岳阳楼记》更直接：目录根本没有这一部，我凭印象写了进去。

**一类是依据不够硬。** 《中论》我系徐干卒年（217），但卒年不是成书之年；《桃花源记》旧系永初二年而学界自太元至永初各有其说；《六祖坛经》断唐而宗宝本成于至元——本体之年不可考。三条都撤了。

**一类是代限本身该改。**

- **魏自 196 起算**。目录以建安七子属魏（《登楼赋》《典论》《嵇康诗全集》皆断魏），而建安元年汉献帝尚在位。代限若从 220 受禅起算，这一批便无一条能系年。既从目录之例，年限也当随之。
- **北魏下探至 550**。《齐民要术》成于东魏武定间（533–544），而北魏亡于 534。目录无「东魏」一段，以「北魏」统后魏东西分裂之世，故下限取东魏之末。

**还有一类，是两表各有各的道理。** 《宋书》断南朝梁——沈约仕梁，四库题「梁沈约撰」；而书成于齐永明六年二月上纪传。这一条我改了断代表（梁→齐），因为断代表自己的第一例写明「以成书之时为断」，永明六年是硬依据。

但同类的事不都能这么办。《文心雕龙》成于齐末而刘勰仕梁、《西湖梦寻》自序于清康熙十年而张岱是明遗民、《武林旧事》周密入元后追记临安、《思旧赋》向秀作于魏景元四年而目录题晋向秀——目录于**人**的题署自有旧例：遗民不入新朝，一生历两代者从其仕宦之代。两例相违时，年不必改，代也不必改，**改哪一边都是以我之见掩旧目之例**。故别立 `ERA_EXEMPT` 一表，一条一由，使自校知其故而不报。

此表宜少不宜多，现五条。凡入此表者，须说得出目录何以如此题署；脚本另有一校，凡豁免而年其实落在代内者报「赘条」，逼着把过时的豁免撤掉。

## 五、上屏

`yearText(year, t)` 在 `app/world/siku.ts`，无年返回空串，由调用处决定整行不印还是留白。现有四处：

| 处 | 样子 |
|---|---|
| 长卷·书脊名签 | `宋 · 别集 · 1082年` |
| 长卷·右栏 | 另起一行 `成书 1082年` |
| 四库·书卡副行 | `汉 · 班固 · 82–111年` |
| 四库·读书页天头 | 同上（`meta.json` 无年，取自目录的 `entry.year`） |

**屏上只印公元，不印年号。** 年号要印得对，得逐条知道那一年属哪个帝的哪个号；而年表所据的依据里年号本已写明（每条之后那一句），上屏再印一道，一来挤，二来一旦与依据不合便是两处打架。

英文一套在 `app/i18n/en.ts`：公元前作 `"91 BC"`，一段作 `"104–91 BC"`（同在公元前者纪元只出一次）；**公元后不带 AD**——目下书名年份无歧义，带上反倒像碑铭，只公元前须标，不标便读反了。

## 六、自校五事

`node scripts/siku-year.mjs --check` 只校不写，任一不合即非零退出：

1. 表里有目录所无之名（key 打错，或书根本不在目录上）
2. 豁免表之书不在年表内（豁免了一部没系年的书）
3. 年式不合：非整数、段之两端倒置、落在公元零年
4. 年出界：早于 -2000 或晚于今年
5. 年不在该书之代以内（豁免表所列者除外）
6. 豁免表有赘条：年其实落在代内，无须豁免

**目录一动必重跑**，与 `siku-dedup.mjs --check`、`siku-era.mjs --check` 同例。写入时，凡从表里撤下之书，其 `year` 字段亦一并从目录删净，故此脚本幂等。

此脚本与 `siku-era.mjs` 一样**不得进 JS bundle**：它是生成目录的一道工序，不是运行时代码。
